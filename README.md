# Soulgame 首发 1.0 · 可点击原型

纯 HTML + CSS + JS，不用构建，直接用浏览器打开 `index.html`（电脑上会显示成手机外框）。
依据：《Soulgame 首发 1.0 需求文档》，在 V7 原型上裁剪而来。

## 包含
- 登录页只有“开始游戏”（游客登录），协议和隐私政策可点开
- 新手礼包 1,500 金币、快速开始引导
- 首页：快速开始（4 个场次）、本地对战、玩法说明；底部“游戏”“我的”两个 Tab
- 匹配：约每 4 局有 1 局等满 10 秒由机器人补位（页面和真人局一样）、取消匹配退还底注
- 对局：回合计时、超时、认输、对手资料卡、举报（原因两项）
- 结算：胜负和金币变化、再来一局、大厅
- 金币不足：免费补助（每天 2 次、每次 300，示例）、换个场次、本地对战
- 我的、钱包与收支明细、设置（语言、音效、协议、联系我们、版本）、注销账号

## 不包含
好友、私聊、好友房、签到和任务、商城和充值、会员、通话、表情和快捷语、局内语音、第三方登录、编辑资料、背包、战绩。

## 演示用
设置 → “演示调试”里有金币清零、重置今天的免费补助次数、重置演示（正式包没有）。
数据存在浏览器 localStorage（键 `soulgame.v10`），和 V7 预览分开。

## 验证
`.stage/look-v10.mjs` 是无头 Chrome 的端到端脚本（26 项检查）：`cd .stage && node cdp.mjs look-v10.mjs shots-v10`
